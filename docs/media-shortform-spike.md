# 키워드 기반 숏폼 기술 스파이크

## 목적

운영 자동화에 앞서 Trendzip 키워드와 설명을 세로형 MP4로 재현 가능하게 렌더링할 수 있는지 검증한다. 첫 결과물은 내부 검수용 무음 샘플이며 공개 게시하지 않는다.

## 기술 결정

- 렌더러: React 컴포넌트로 장면을 재사용할 수 있는 Remotion을 사용한다.
- 인코딩: Remotion 로컬 렌더의 H.264, yuv420p MP4를 사용한다.
- 규격 검사: `ffprobe-static`으로 OS의 FFmpeg 설치와 무관하게 출력 메타데이터를 확인한다.
- 폰트: SIL Open Font License로 배포되는 Fontsource의 Noto Sans KR Variable 패키지만 사용한다.
- 입력: 운영 DB를 호출하지 않고 출처와 샘플 여부가 명시된 JSON fixture를 사용한다.
- 외부 자산: YouTube 영상·썸네일, 작품 이미지, 제3자 음원은 사용하지 않는다.

## 라이선스와 정책 판단

2026-08-18 확인 기준으로 Remotion은 개인과 3인 이하 팀에 무료 라이선스, 상업적 사용과 자동화를 허용한다. 팀 규모나 사용 주체가 바뀌면 렌더링 자동화를 확대하기 전에 라이선스를 다시 확인한다.

YouTube 수익화 정책은 원본성과 실질적인 교육·해설 가치를 요구하며, 대량 생산된 반복 템플릿이나 해설이 거의 없는 이미지·텍스트 슬라이드쇼를 비진정성 콘텐츠로 판단할 수 있다. 따라서 후속 구현에서도 다음 원칙을 유지한다.

- 키워드별 근거와 분석 내용이 실질적으로 달라야 한다.
- 운영 게시 전 사람의 사실·품질 검수를 필수로 한다.
- 외부 미디어를 사용하려면 별도로 상업적 이용 권리를 확보한다.
- 현실적으로 보이는 합성 인물·사건·장소를 추가하면 업로드 시 합성 콘텐츠 공개 여부를 검토한다.

## 고정 샘플

`메이드 인 코리아` 작품명 분리 사례를 사용한다. Disney+ 공식 페이지에서 확인되는 작품 형식과 출연 정보만 사용하며, 실제 운영 순위가 아니라는 점을 영상 전체의 `기술 검증용 SAMPLE` 라벨로 표시한다.

fixture의 UTM 링크는 후속 YouTube 유입 분석 형태를 미리 검증하기 위한 값이다. 스파이크에서는 링크를 게시하거나 GA4 캠페인 수집까지 확인하지 않는다.

## 검수 체크리스트

- [x] 1080x1920, 30fps, 36초 H.264 MP4다.
- [x] 모든 장면에서 샘플 라벨과 날짜가 보인다.
- [x] 모바일 세로형 미리보기에서 핵심 자막을 읽을 수 있다.
- [x] 긴 한국어 문장이 안전 영역 밖으로 잘리지 않는다.
- [x] 작품 정보가 공식 근거와 일치하고 출처가 식별된다.
- [x] 외부 영상·썸네일·음원·불명확한 폰트가 포함되지 않는다.
- [x] CTA가 실제 운영 도메인과 UTM 캠페인을 사용한다.
- [x] 무음 샘플임을 확인하고 공개 게시하지 않는다.
- [x] 사용자가 최종 MP4를 처음부터 끝까지 재생하고 사람 검수를 승인한다.

## 스파이크 결과

2026-08-19 로컬 Mac에서 사용자 실습을 반영한 뒤 `npm run render:sample`을 다시 실행해 `media/out/made-in-korea.mp4`를 생성했다. 결과물은 약 1.8MB이며 Git에는 포함하지 않는다.

렌더 명령에 포함된 ffprobe 검사가 다음 항목을 모두 통과했다.

- 해상도: 1080x1920
- 프레임레이트: 30fps
- 길이: 36초
- 비디오: H.264, yuv420p
- 오디오 스트림: 0개

샘플 플래그가 제거된 fixture는 렌더링 전에 비정상 종료했고, 날짜 형식과 실제 달력 날짜에 대한 테스트 세 건도 통과했다. 훅·요약·이유·근거·CTA 대표 프레임에서는 텍스트 잘림이나 요소 겹침이 없었으며, 사용자가 최종 MP4 전체 재생과 사람 검수를 승인했다. Remotion을 결정적 렌더러로 사용하는 기술적 타당성은 확인했다. 무음 텍스트 중심 샘플 이후 MEDIA-002에서 TTS와 장면 동기화를 검증했고, 운영 자동화 전에는 숏폼 선정·편집·발행 정책을 먼저 적용한다.

## 예상 비용과 후속 결정

- 현재 개인 개발과 로컬 렌더링은 Remotion 무료 라이선스 범위로 판단한다.
- 로컬 Mac에서 렌더링하므로 첫 스파이크의 별도 인프라 비용은 없다.
- 렌더링 자동화 주체, 팀 규모, 월 생성량이 바뀌면 Remotion 라이선스와 Mac mini 자원 사용량을 다시 산정한다.
- TTS와 오디오 동기화 검증 후에는 [숏폼 선정·편집·발행 정책](media-publishing-policy.md)을 기준으로 운영 후보와 사람 승인 자동화를 다음 작업에서 설계한다.
