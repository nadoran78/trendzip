# 숏폼 선정·편집·발행 정책

## 목적

Trendzip이 매일 수집하는 키워드를 유익한 숏폼으로 제작하되, 데이터만 바꾼 반복·대량 생산 콘텐츠를 만들지 않도록 운영 경계를 정한다. 이 문서는 공개 발행 여부를 판단하는 정책이며, 특정 발행 횟수나 편집 형식이 YouTube 정책 준수를 보증한다는 안전 기준은 아니다.

## 적용 범위

- YouTube Shorts에 공개할 Trendzip 키워드 영상에 적용한다.
- 운영 키워드 선정부터 대본, 편집, 검수, 발행 일정과 사후 대응까지 다룬다.
- YouTube 외 SNS에도 같은 원칙을 적용하되, 플랫폼별 정책은 발행 자동화 전에 따로 확인한다.

## YouTube 공식 기준과 내부 정책

2026-08-21에 YouTube 공식 문서를 확인했다. YouTube는 같은 인트로·아웃트로나 유사한 형식을 사용하더라도 영상별 핵심 내용이 실질적으로 다르고 창의적·교육적 가치를 제공하는 경우를 수익화 가능한 예시로 든다. 반면 템플릿에서 일부 표현만 바꾼 영상이 서로 대체 가능하게 보이면 비진정성 콘텐츠로 판단될 수 있다.

YouTube 스팸 정책은 AI나 자동화 도구로 최소한만 바꾼 유사한 콘텐츠를 대량 생산하는 행위를 금지한다. 이 정책은 공개 영상뿐 아니라 비공개·일부 공개 콘텐츠에도 적용되므로, 비공개 업로드를 반복 콘텐츠 안전 지대로 보지 않는다.

YouTube는 현실적으로 보이는 인물, 사건이나 장소를 AI로 의미 있게 생성·변경한 경우 업로드 시 공개를 요구한다. 대본 초안, 자막, 인포그래픽 제작 보조는 그 자체로 필수 공개 대상이 아니지만, 실제 인물의 말이나 행동을 합성하거나 실제로 없던 장면을 현실적으로 추가하면 반드시 다시 판단한다.

공식 참고 자료:

- [YouTube 채널 수익 창출 정책](https://support.google.com/youtube/answer/1311392?hl=ko)
- [YouTube 스팸 정책](https://support.google.com/youtube/answer/2801973?hl=ko)
- [AI로 변경되거나 생성된 콘텐츠 공개](https://support.google.com/youtube/answer/14328491?hl=ko)

아래의 발행 횟수, 재발행 기간, 편집 순환 기준은 YouTube가 제시한 수치가 아니라 Trendzip이 보수적으로 시작하기 위해 정한 내부 정책이다.

## 콘텐츠 식별자

키워드 문자열만으로 중복을 판단하지 않는다. 하나의 제작 후보는 다음 조합으로 식별한다.

| 항목 | 의미 | 예시 |
|---|---|---|
| `topicKey` | 정규화한 대표 키워드로 생성한 안정적인 시스템 키 | `keyword-12자리hash` |
| `eventKey` | 같은 실행에서 같은 사건 초안을 식별하는 시스템 키 | `keyword-12자리hash:why-now:crawl-501` |
| `audienceAngle` | 시청자에게 답할 핵심 질문 | `왜 코리아가 아닌 전체 작품명으로 보나` |
| `editorialFormat` | 내용을 풀어내는 편집 형식 | `PERSON_WORK_RELATION` |
| `evidenceRefs` | 사실과 관심 원인을 직접 뒷받침하는 근거 | 공식 작품 페이지, 메인 예고편 |
| `conclusion` | 영상이 제공하는 고유한 정리 | `문맥 없는 단어보다 작품명이 관심 원인을 잘 설명한다` |

`topicKey`와 `eventKey`는 Gemini가 만들지 않는다. 시스템이 정규화한 대표 키워드로 `topicKey`를 만들고, `editorialFormat`, `sourceCrawlRunId`를 결합해 `eventKey`를 결정적으로 생성한다. 문구가 달라져도 같은 입력이면 같은 값을 사용한다. 이 키는 기술적 중복 식별자이며 새로운 사건임을 증명하지 않는다. 사건의 실질적인 차이는 `audienceAngle`, 직접 근거와 결론으로 판단한다.

다음 둘 중 하나라도 해당하면 동일하거나 서로 대체 가능한 콘텐츠로 본다.

1. `topicKey`, `eventKey`, `conclusion`이 같다.
2. 같은 근거와 대본 흐름을 유지한 채 키워드, 세대나 이미지만 바꾸었다.

같은 키워드라도 새로운 직접 근거가 있고, 훅·근거·전개·결론 중 두 가지 이상이 실질적으로 다르면 신규 콘텐츠로 검토할 수 있다. `eventKey`가 다르다는 사실만으로 신규 콘텐츠로 보지 않는다.

## 후보 판정

| 상태 | 의미 | 선택 기준 |
|---|---|---|
| `ADOPT` | 제작 초안으로 전환한다. | 현재성, 관심 이유, 직접 근거, 차별화된 관점과 권리 경계가 모두 명확하다. |
| `HOLD` | 보강하거나 발행 시점을 다시 판단한다. | 후보 가치는 있지만 사실, 근거, 중복, 권리 또는 일정 조건이 충분하지 않다. |
| `REJECT` | 현재 제작 대상에서 제외한다. | 범용어, 문맥 의존어, 근거 불일치, 사실 오류, 중복 콘텐츠, 권리 위험 또는 낮은 정보 가치가 해소되지 않는다. |

### `ADOPT` 필수 조건

1. 가장 최근의 성공한 크롤링 결과가 판정 시점으로부터 72시간 이내다.
2. 키워드가 왜 뜨는지 한 문장으로 설명할 수 있다.
3. 최소 하나의 직접 근거 영상과 사실관계를 확인할 1차 또는 공식 출처가 있다.
4. 근거는 키워드와 설명하려는 관심 계기를 직접 뒷받침한다.
5. 최근 발행 목록과 비교했을 때 동일 콘텐츠가 아니다.
6. 외부 영상, 음원, 사진과 썸네일을 사용하지 않거나 상업적 이용 권리를 확보했다.

### 즉시 `REJECT`

- `게임`, `리뷰`, `방송`, `영상`처럼 단독으로 관심 원인을 설명하지 못하는 범용어다.
- 전체 작품명·인물·사건에서 일부만 떼어낸 문맥 의존어다.
- Gemini 설명과 직접 근거가 다른 작품, 인물이나 사건을 가리킨다.
- 추측을 사실로 단정해야만 대본이 성립한다.
- 최근 영상과 훅, 근거, 전개, 결론이 사실상 같다.
- 권리를 확인할 수 없는 외부 자산을 사용해야만 제작할 수 있다.

## 관련 키워드 통합

같은 사건에서 파생된 키워드는 각각 영상으로 만들지 않고 하나의 제작 후보로 묶는다.

- TEEN과 TWENTY에 동시에 등장한 같은 키워드
- 작품명과 출연자
- 대회명, 팀명과 게임명
- 아티스트와 신곡명
- 플랫폼명과 그 안의 특정 콘텐츠

통합한 후보는 가장 구체적인 작품·사건·콘텐츠를 대표 `topicKey`로 선택하고, 나머지 키워드는 관계를 설명하는 근거로만 사용한다.

## 재발행과 반복 방지

- 같은 `topicKey`는 최근 공개일로부터 30일 동안 다시 발행하지 않는다.
- 30일 안에 새로운 관심 계기와 직접 근거가 확인된 경우만 예외 검토한다.
- 예외는 신규 근거, 기존 영상과 다른 핵심 질문, 훅·근거·전개·결론 중 두 가지 이상의 실질적 변화를 모두 충족해야 한다.
- 예외를 승인할 때는 이유와 비교 대상 영상을 발행 기록에 남긴다.
- 같은 카테고리를 세 편 연속 발행하지 않는다.
- 신규 후보가 없다면 발행하지 않는다. 정해진 횟수를 채우기 위해 기존 후보를 재사용하지 않는다.

## 편집 차별화

### 고정해도 되는 브랜드 요소

- 로고, 색상, 폰트와 기본 자막 스타일
- 짧은 인트로와 아웃트로
- Trendzip 도메인과 기본 CTA 표현
- 세로형 안전 영역과 접근성 기준

### 영상마다 달라야 하는 핵심

- 첫 장면의 질문과 주장
- 사건을 풀어내는 스토리 순서와 장면 수
- 핵심 근거, 데이터 표현과 시각 자산
- 내레이션의 관점과 결론
- 시청자가 얻는 구체적인 인사이트

새 영상은 최근 영상과 비교해 훅, 장면 구성, 근거, 결론 중 최소 두 가지를 실질적으로 다르게 만든다. 짧은 확대, 색상 교체나 문구 순서 변경만으로는 차별화로 보지 않는다.

### 편집 형식

| 코드 | 핵심 질문 | 추천 상황 |
|---|---|---|
| `WHY_NOW` | 왜 지금 갑자기 떴나 | 신작, 컴백, 대회, 사건 직후 |
| `KEYWORD_PRIMER` | 이 키워드는 무슨 뜻이고 어떤 맥락에서 쓰이나 | 신조어, 크리에이터, 게임·팬덤 용어 |
| `PERSON_WORK_RELATION` | 인물과 작품이 왜 함께 뜨나 | 배우·작품, 아티스트·곡 |
| `EVENT_KEYWORD_MAP` | 하나의 사건이 어떤 키워드를 만들었나 | 대회·팀·선수, 작품·출연진 |
| `CONTEXT_TIMELINE` | 어떤 일들이 이어지며 관심이 커졌나 | 발표, 예고편, 방송, 경기처럼 여러 계기가 있는 후보 |
| `WEEKLY_BUNDLE` | 이번 주의 관련 흐름은 무엇인가 | 단일 후보보다 연결된 여러 키워드가 유익한 경우 |

키워드 순위는 Trendzip이 후보 선정과 탐색을 위해 만든 내부 지표로 두고, 순위 변동 자체를 독립적인 영상 주제로 삼지 않는다. 급상승이 신규 사건을 발견하는 단서가 될 수는 있지만, 영상의 중심은 `WHY_NOW`에서 다루는 실제 관심 계기여야 한다.

`WHY_NOW`는 초안 생성 시점으로부터 30일 안에 게시된 근거 영상이 최소 하나 있는지 진단한다. 최근 근거가 없으면 검수 경고를 남기되 자동으로 후보를 탈락시키지는 않는다. `KEYWORD_PRIMER`는 용어와 맥락을 설명하는 대표 영상이 목적이므로 오래된 근거 영상도 허용한다.

10대와 20대 후보가 대부분 같고 세대별 점수도 각각의 기준 안에서 산정되므로, 세대 비교를 독립 편집 형식으로 두지 않는다. 향후 일정 기간 반복되는 후보·근거 차이가 확인되면 별도 정책 리뷰를 거쳐 다시 도입한다. 데이터가 뒷받침하지 않는 세대 특성을 대본에서 추론하지 않는다.

직전 두 편과 같은 `editorialFormat`은 사용하지 않는다. 다만 실제 콘텐츠가 충분히 다르고 대체 형식이 부적절한 경우에는 검수 사유를 남기고 예외를 허용한다.

## 발행 단계와 주기

| 단계 | 발행 방식 | 진입·유지 기준 |
|---|---|---|
| `LOCAL_DRAFT` | 로컬에서만 대본·음성·영상을 검수한다. | 정책 적용과 제작 경로가 안정화될 때까지 유지한다. |
| `PRIVATE_PILOT` | 승인된 결과만 YouTube 비공개로 업로드하여 메타데이터와 재생을 확인한다. | 비공개도 정책 적용 대상이므로 검수 통과 결과만 업로드한다. |
| `PUBLIC_PILOT` | 4주간 주 2회, 연속된 날짜 없이 공개한다. | 최초 8편을 전체 재생 검수하고 발행 기록을 남긴다. |
| `SCALED` | 최대 주 3회까지 검토한다. | 8편 이상, 정책·저작권 문제 0건, 중대한 사실 정정 0건, 형식별 품질과 유지율 기준선 확보 후 확대한다. |

주 2회는 발행 목표가 아니라 상한이다. `ADOPT`할 후보가 없거나 검수를 끝내지 못하면 발행하지 않는다. 모든 단계에서 사람 승인을 유지하며, `SCALED`는 승인을 생략하는 단계가 아니다.

## 제작과 검수

### 대본 원칙

- 핵심 주장은 공식 출처와 근거 영상이 확인하는 범위 안에서만 작성한다.
- 기존 키워드 설명은 후보 선정용 참고 문맥이며 독립적인 사실 근거로 사용하지 않는다.
- Gemini는 선택 영상 ID와 영상 제목·채널명의 실제 원문 발췌만 고른다.
- 시스템은 검증된 발췌를 fact card로 만들고 핵심 이유와 근거 영상 목록을 결정적으로 생성한다.
- Trendzip의 순위·점수·연속 노출 주차는 후보 선정용 내부 신호이며 공개 대본의 사실 주장으로 사용하지 않는다.
- 검색량, 연령대별 관심과 YouTube 조회수를 서로 같은 지표처럼 표현하지 않는다.
- 상관관계를 인과관계로 단정하지 않는다.
- 추측이 필요하면 추측임을 명시하거나 대본에서 제외한다.
- 시스템 조립문도 초안으로만 사용하고 공개 전에 사람이 fact card와 출처 경고를 대조한다.

### 권리와 AI 표시

- 기본 시각 자산은 Trendzip 디자인, 직접 제작한 데이터 시각화와 상업적 이용이 가능한 자산으로 구성한다.
- YouTube 영상·썸네일, 방송·영화 클립과 음원은 권리 확인 없이 다운로드해 사용하지 않는다.
- 대본·자막·인포그래픽 제작 보조와 일반적인 TTS 사용 여부를 내부 기록에 남긴다.
- 현실적인 인물·사건·장소를 의미 있게 AI로 생성·변경하거나 실제 인물을 모방한 음성을 쓰면 YouTube 공개 항목을 필수로 검토한다.
- 영상 설명에 `AI 도구를 제작에 활용했고 Trendzip이 사실과 품질을 검수했습니다.`라는 자체 투명성 문구를 기본으로 둔다. 이 문구는 YouTube의 필수 AI 공개 설정을 대체하지 않는다.

### 발행 전 사람 검수

- [ ] 업로드 대상은 내부 검수 문구가 없는 `PUBLIC_CANDIDATE` 렌더 아티팩트이며, 검수 상태는 아티팩트 이력에서 확인했다.
- [ ] 크롤링 기준 시각과 판정 시점이 72시간 이내다.
- [ ] 시스템 생성 `eventKey`의 주제·형식·크롤링 실행이 초안 입력과 일치한다.
- [ ] 각 `evidenceClaim`의 원문 발췌가 선택 영상 제목 또는 채널명에 실제로 존재한다.
- [ ] `WHY_NOW`의 최근 근거 경고가 있으면 실제 관심 계기의 현재성을 별도로 확인했다.
- [ ] 핵심 설명과 숫자를 공식 또는 신뢰할 수 있는 출처와 대조했다.
- [ ] 확인되지 않은 사실, 과장과 인과 단정이 없다.
- [ ] 최근 발행물과 실질적으로 다르고 30일 재발행 기준을 준수했다.
- [ ] 직전 두 편과 같은 편집 형식을 반복하지 않았다.
- [ ] 외부 시각·음원 자산의 상업적 이용 권리를 확인했다.
- [ ] 제목과 썸네일이 영상에서 확인하지 않은 내용을 암시하지 않는다.
- [ ] `1.3x` TTS 발음, 음량, 자막 싱크와 영상 전체를 재생해 확인했다.
- [ ] AI 공개 설정과 설명란 투명성 문구를 판단했다.
- [ ] CTA가 정보 전달보다 큰 비중을 차지하지 않고 연결 위치가 안전하다.

## 발행 메타데이터

제목은 핵심 주제와 관점을 그대로 드러내고, 설명란에는 확인한 출처와 AI 제작 보조 문구를 남긴다. 영상은 Trendzip의 정보를 전달하는 것을 주목적으로 하며, 외부 사이트 유입만을 위한 짧은 홍보물로 만들지 않는다.

필수 기록:

- 영상 제목과 설명
- `topicKey`, `eventKey`, `audienceAngle`, `editorialFormat`
- 포함한 키워드 ID와 세대
- 크롤링 실행 ID와 판정 기준 시각
- 근거 참조와 출처 URL
- 대본 버전과 hash
- 사용한 TTS 모델·음성과 AI 제작 보조 내역
- 권리 확인 결과와 AI 공개 판단
- 판정·검수자, 사유와 시각
- 예정·실제 발행 시각과 YouTube 영상 ID
- 정책 경고, 사실 정정과 보류·비공개 이력

## 후속 자동화 상태

MEDIA-004 이후는 아래 상태를 기본으로 사용하되, 실제 저장 모델은 구현 작업에서 확정한다.

```text
CANDIDATE
  -> DRAFT
  -> RENDERED
  -> REVIEW_REQUIRED
  -> APPROVED
  -> UPLOADED_PRIVATE
  -> SCHEDULED
  -> PUBLISHED
```

가지 상태:

- `HOLD`: 근거·시점·권리 보강 전까지 선정을 멈춘다.
- `REJECTED`: 선정 또는 검수에서 제외하고 사유를 보존한다.
- `NEEDS_REVISION`: 대본·음성·영상을 고친 뒤 다시 검수한다.
- `RETIRED`: 발행했지만 정책, 권리, 사실 정정 또는 운영 판단으로 비공개·종료한다.

사람 승인 없이 `REVIEW_REQUIRED`에서 `APPROVED`로 전환할 수 없다. 대본, 근거, 음성이나 렌더링 결과가 바뀌면 기존 승인을 무효화하고 다시 검수한다. MEDIA-004의 자동 편집 단계는 `DRAFT`까지만 만들며 필수 운영자 편집 입력을 요구하지 않는다.

## 샘플 후보 판정

아래 판정은 과거 크롤링에서 나온 표현에 정책을 적용한 문서 검증용 예시다. 실제 발행 판정이 아니며, 재사용할 때는 72시간 현재성과 공식 근거를 다시 확인해야 한다.

| 입력 후보 | 판정 | 통합·편집 형식 | 사유 |
|---|---|---|---|
| `메이드 인 코리아` | `ADOPT` | `코리아`를 포함, `WHY_NOW` | 구체적인 작품명과 공식 작품·예고편 근거로 독립적인 설명을 만들 수 있다. |
| `코리아` | `REJECT` | `메이드 인 코리아`에 통합 | 작품명에서 분리한 문맥 의존어로, 단독으로는 관심 원인을 특정할 수 없다. |
| `게임` | `REJECT` | 없음 | 구체적인 작품, 인물이나 사건이 없는 범용 형식어다. |
| `리뷰` | `REJECT` | 없음 | 콘텐츠 형식을 가리킬 뿐 현재 관심 원인을 설명하지 못한다. |
| `김부장` | `HOLD` | `소지섭`과 통합 후 재판정 | 기존 설명에서 작품·방송사·플랫폼 정보가 충돌했으므로 공식 출처로 사실을 먼저 확정해야 한다. |
| `소지섭` | `HOLD` | `김부장`의 인물·작품 설명에 통합 | 같은 작품 사건을 근거로 삼는다면 독립 영상은 중복이다. |
| `호프` | `ADOPT` | `황정민`·`조인성`을 포함, `EVENT_KEYWORD_MAP` | 작품 발표나 예고편 공개라는 현재 사건을 공식 출처로 확인하면 파생 키워드를 하나의 콘텐츠로 묶을 수 있다. |
| `황정민` | `HOLD` | `호프`에 통합 | 관심 이유가 같은 작품이라면 인물명만 바꾼 독립 영상을 만들지 않는다. |
| `MSI 2026` | `ADOPT` | `T1`·`리그오브레전드`를 포함, `EVENT_KEYWORD_MAP` | 같은 대회 결과와 경기가 원인이면 팀·게임 키워드를 별도 영상으로 반복하지 않는다. |
| `리센느` | `ADOPT` | `Pretty Girl`을 포함, `PERSON_WORK_RELATION` | 아티스트와 곡의 같은 컴백 사건을 하나의 관계 설명으로 만들 수 있다. |

## 사후 모니터링과 중단

다음 중 하나가 발생하면 신규 발행을 일시 중단하고 해당 영상을 검토한다.

- YouTube 정책 경고, 수익화 제한 또는 스팸 의심 신호
- 저작권 신고·이의 제기·라이선스 불명확 자산 발견
- 작품, 인물, 일정이나 수치에 대한 중대한 사실 오류
- 최근 영상의 대본·장면·결론이 서로 대체 가능할 정도로 반복되는 패턴

운영자는 영향 범위를 확인해 설명 정정, 비공개, 삭제 또는 사후 공지를 선택하고 조치·사유·시각을 기록한다. 원인과 재발 방지 조치가 확정되기 전에는 자동 게시를 재개하지 않는다.
